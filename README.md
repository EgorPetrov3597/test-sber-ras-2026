# test-sber-ras-2026

Тестовое задание для отбора на позицию Junior Data Scientist (Сбер).  
Реализация пайплайна анализа диагностических данных детей с РАС: валидация, поиск застоя прогресса, генерация отчётов и графиков. Проект включает тесты и документацию.

## Структура проекта (будет дополнена)

- `src/` – исходный код
- `tests/` – unit-тесты
- `data/` – входные данные (не включены в репозиторий)
- `output/` – результаты анализа (отчёты, графики)
